# 锂电池析锂（Lithium Plating）无损检测方法系统验证报告

- 版本：v1.0
- 日期：2026-11-02
- 技术范围：纯经典信号处理 + 物理可解释统计，**零深度学习、零模型训练**
- 配套代码：`D:\项目\01_在研项目\析锂无损检测方法验证`

---

## 1. 摘要

本项目对公开文献中四类主流的锂电池析锂无损检测方法（M1 弛豫肩部、M2 dQ/dV
峰移、M3 库仑效率下降、M4 充电 kink）进行了工程实现与系统验证。验证分为两层：

1. **合成真值验证**：在含明确析锂真值的物理合成电池上，四方法在 16 电芯
   （8 析锂 / 8 对照）上灵敏度与特异度均达到 1.00。
2. **真实数据交叉验证**：在 Oxford、NASA、MATR-10 三个国际公开数据集的 16 个
   电芯上运行。M1/M3/M4 全部阴性，M2 仅在 Oxford 8 个深度老化电芯的寿命中后期
   报峰移。

由于公开真实数据**无拆解析锂真值**，本报告不宣称检测准确率，而是给出"多方法
一致性证据 + 工况物理预期对照"，并对各方法的适用边界与可信度进行分级。核心
结论是：**在本批常规工况（无强析锂预期）真实电芯上，没有任何电芯获得多方法
一致的析锂阳性证据；M2 的峰移证据对阈值敏感且物理上无法与正常老化区分，是
可信度最弱的方法。**

---

## 2. 研究目标与方法学原则

### 2.1 目标

- 实现 M1~M4 四种检测算法并统一接口；
- 用含真值的合成数据量化方法的灵敏度/特异度与检测滞后；
- 在多个真实数据集上交叉验证，评估方法一致性与工况依赖；
- 明确各方法适用边界，避免"调参调出结论"。

### 2.2 方法学原则

1. **不做静态阈值调参**：所有判据基于跨循环/趋势的物理可解释对照，而非单点
   绝对阈值。所有阈值集中在 `configs/config.yaml`，禁止硬编码。
2. **阈值可审计**：提供阈值敏感性扫描，量化结论对阈值的依赖。
3. **无真值不宣称准确率**：真实数据结论仅表述为一致性证据与物理预期对照。
4. **可复现**：合成数据采用 `hashlib.md5` 确定性随机种子（Python 内置 `hash()`
   会随进程随机化，已弃用）。

## 3. 数据与环境

### 3.1 运行环境

Python 3.13，关键依赖：numpy 2.5、scipy 1.18、pandas 3.1、scikit-learn 1.9、
ruptures 1.1、matplotlib 3.11、PyYAML。

### 3.2 合成数据（真值锚点）

`synthetic.py` 基于 OCV(SOC) + 内阻 + RC 极化 + 弛豫构建，可在指定循环注入析锂，
使 M1 肩部、M2 峰移、M3 CE 下降、M4 kink 随析锂进度（onset 后 20 循环内 0→1）
自然出现。电压噪声 0.1 mV、rest 段 30 s 采样，均按真实 Arbin 数据校准。

### 3.3 真实数据集与已确认的"坑"

| 数据集 | 电芯数 | 工况 | 关键特征/坑 |
| --- | --- | --- | --- |
| Oxford OBD1 | 8 | 40℃，0.53C，无静置 | 时间字段为 MATLAB datenum（天），须 ×86400 转秒；无长静置，不能用于 M1 |
| NASA PCoE | 3 | 24℃，CC-CV，0.28C | 低电流"弛豫"实为 CV 尾电流，须排除；CE 存在周期性可恢复波动 |
| MATR-10 | 5 | 多倍率，0.02C 特征化 | 每电芯 15-16 个真实 rest（电流严格 0，30s 采样，噪声 0.06-0.08mV），是 M1 理想数据 |

已修复的误判：NASA CV 尾电流误判为弛豫（加电压钳位判据）；MATR-10 的 C/100、
C/80 慢放电因电流本身 <C/50 被误判（改为只在独立 rest 段检测）。

## 4. 方法卡

### 4.1 M1 电压弛豫肩部法

- **物理原理**：充电结束后静置，若发生析锂，析出锂重新嵌回的混合电位效应使
  弛豫速率出现特征肩部。
- **算法流程**：SG 平滑求弛豫速率 rate = −dV/dt → `IsotonicRegression` 保序回归
  拟合单调递减基线 → 在残差上检测肩部峰 → 要求连续 `persist_n=2` 个 rest 确认。
- **为何不用直接找极小**：弛豫速率本身单调指数衰减（std 3e-5），肩部被强下降
  趋势淹没，必须先去单调基线。
- **关键参数**：sg_window 11、residual_prominence 4e-6、persist_n 2。
- **验证表现**：合成数据灵敏度/特异度 1.00，检测滞后约 17-19 循环；真实数据
  全部阴性（早期单段边缘报警已被 persist 正确抑制）。
- **适用边界**：必须有真实长静置（≥30 min）；Oxford 无静置不可用。

### 4.2 M2 dQ/dV 峰移/分裂法

- **物理原理**：低倍率 dQ/dV 曲线的石墨 staging 峰随析锂发生偏移、分裂或新峰。
- **算法流程**：q(v) 重采样到统一电压网格（3.3-4.2V，200 点）→ 固定窗口平滑 →
  按相对中位水平提取 top 5 主峰 → 双指针顺序匹配（允许峰丢失/新增）→ persist 确认。
- **关键工程改进**：统一网格消除采样率差异；顺序匹配替代贪心最近邻，避免峰数
  变化时的跨峰错配（曾出现 3.516 错配到 3.65 的虚假 0.134 位移）。
- **关键参数**：grid 200、max_match_gap 0.04、shift_alarm 0.03、persist_n 2。
- **验证表现**：合成数据 1.00/1.00，滞后约 20 循环；真实数据仅 Oxford 8 电芯在
  cycle 1100-1800 报峰移。
- **适用边界（重要局限）**：**峰移非析锂特异**，正常老化（SEI 生长、活性材料
  损失、阻抗上升）同样导致峰移。Oxford 为 40℃ 高温，高温抑制析锂、主要加速 SEI
  与材料退化，故其峰移更可能是正常老化；且阳性对阈值敏感（见第 7 节）。

### 4.3 M3 库仑效率持续下降法

- **物理原理**：析锂使充电电荷无法全部在放电时回收，CE 持续下降、不可逆容量
  加速损失。
- **算法流程**：逐循环 CE = 放电容量/充电容量 → pandas 居中滚动均值 → ruptures
  PELT 变点检测（仅记录，不单独触发）→ 阳性以持续 CE 下降（≥0.02）为唯一判据。
- **关键收口**：变点单独触发会把平稳序列偶发变点、以及 NASA 周期性可恢复 CE
  波动（0.984/0.997 交替）误判，故变点仅用于起始定位，不独立触发。
- **关键参数**：rolling_window 5、ce_drop_alarm 0.02、pelt_pen 1.0。
- **验证表现**：合成数据 1.00/1.00，滞后约 5 循环（四方法中最早）；真实数据
  全部阴性。
- **适用边界**：需准确的充放电容量配对；须区分可恢复的工况性 CE 波动。

### 4.4 M4 充电 kink 拐点法

- **物理原理**：析锂在高 SOC 引起随老化新出现并增强的充电曲线凹陷（kink）。
- **算法流程**：各循环 CC 段 dV/dQ 重采样到统一 SOC 网格 → 前 10 循环中位曲线
  为基准 → 检测高 SOC（0.50-0.90）相对基准新出现的负向凹陷 → persist 确认。
- **为何不用绝对凹陷**：正常石墨 staging 在 CC 段 dV/dQ 本就有显著谷，静态绝对
  阈值无法区分，必须跨循环基准对照；CV 段 dV/dQ 发散，须先排除。
- **关键参数**：soc_grid 100、baseline_cycles 10、min_prominence 0.02、
  rel_prominence 0.30、persist_n 2。
- **验证表现**：合成数据 1.00/1.00，滞后约 17 循环；真实数据全部阴性。
- **适用边界**：需可识别的 CC 段与足够的健康基准循环。

热力图见 `results/figures/fig2_real_positive_heatmap.png`。

### 6.2 方法一致性

电芯级二分类的 Cohen Kappa 因多数方法全阴性而接近 0 或无定义（单标签）。这本身
说明：在无强析锂预期的常规工况下，各方法没有形成相互印证的阳性簇。

### 6.3 工况物理预期对照

- Oxford：40℃ 高温、0.53C。高温下负极动力学与扩散改善，**析锂倾向低**，老化以
  SEI/材料退化为主。M2 在此报峰移，与正常老化的物理预期一致，不支持析锂结论。
- NASA：24℃ 标准 CC-CV，无析锂强预期，四方法阴性，符合预期。
- MATR-10：低倍率特征化，M1 基于真实 rest 亦未检出肩部，符合预期。

## 7. 阈值敏感性分析

对各方法关键阈值在基线 0.5-1.5 倍扫描，阳性电芯数：

| 方法 | 参数 | ×0.5 | ×0.75 | ×1.0 | ×1.25 | ×1.5 |
| --- | --- | --- | --- | --- | --- | --- |
| M1 | residual_prominence | 1 | 0 | 0 | 0 | 0 |
| M2 | shift_alarm | 9 | 8 | 8 | 2 | 2 |
| M3 | ce_drop_alarm | 3 | 2 | 0 | 0 | 0 |
| M4 | min_prominence | 0 | 0 | 0 | 0 | 0 |

曲线见 `results/figures/fig3_threshold_sensitivity.png`。

解读：

- **M4 最稳健**：全区间 0 阳性，阴性结论不依赖阈值。
- **M1/M3 基线阴性稳健**：仅在阈值明显收紧（×0.5）时才出现少量阳性。
- **M2 对阈值敏感**：阳性数在 8 与 2 之间跳变，峰移处于 0.03-0.04V 临界区，
  结合其物理非特异性，M2 证据可信度最低。

## 8. 结论与证据等级

1. 合成真值上四方法均达到灵敏度/特异度 1.00，证明算法实现正确、物理特征可被
   稳定检出。
2. 真实常规工况 16 电芯上，**无任何电芯获得多方法一致的析锂阳性证据**，整体
   与"这些工况无明显析锂"的物理预期一致。
3. 方法可信度分级（真实数据）：
   - **M4：高**（基准对照 + 阈值稳健）；
   - **M1/M3：中高**（需特定数据条件，阴性结论稳健）；
   - **M2：低**（峰移非特异 + 阈值敏感）。
4. 推荐工程用法：**以多方法一致性 + 工况物理预期联合判定，M2 仅作辅助线索，
   不单独支撑析锂结论。**

## 9. 局限与后续工作

- 公开数据无拆解真值，无法在真实电芯上给出真实准确率，只能给出证据等级。
- M2 单电芯提前 60 循环报警、峰移非特异，需进一步结合"单向持续 + 多方法一致"
  改进，而非继续收紧阈值。
- 可选加分项：合成闭环完整 ROC 曲线、退化对齐分析、低温/高倍率工况扩充（当前
  数据集以常温/高温为主，缺少强析锂工况真值）。
